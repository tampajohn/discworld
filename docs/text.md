# English V1 text and positioned speech

ENGLISH.TXT is a linked sequence of CHUNK_STRING records, each containing up to 64 length-prefixed byte strings. V1 lengths are single unsigned bytes, including values above 127; V2 control-byte rules do not apply. The final chunk in this ISO contains two entries. The checked reader validates all 6850 strings and chunk padding without converting game character codes to Unicode.

The 256-entry font table follows 44 bytes of spacing, shadow, space width, and object-initialization data. Startup tag/talk font handles are 374748 and 375816. Both have 199 glyph images and drawing flags 1. The audit decodes every glyph and lays out all strings with both fonts. Layout centers each line independently, uses missing glyphs as spaces, ignores horizontal glyph animation offsets, and subtracts vertical animation offsets as the reference does. PRINT's horizontal and bottom edge adjustments are implemented for the current 320x200 surface.

PRINT owns its layout and wait state in its script process. Explicit durations use 24 ticks per second and the reference's post-decrement wait. Default text speed uses byte length plus 24 ticks. If speech exists, the single sample channel starts it and the process waits on that playback identity, bounded by the reference's 480-tick timeout. Replacement playback cannot be accidentally stopped by completion of an older PRINT. Subtitles are enabled by default and can be disabled via the engine setting. Scene cancellation drops process-owned text.

TALKAT (98) and TALKATS (104) share the PRINT wait/layout path with four and five arguments respectively. TALKAT uses the actor speech color when subtitles are visible or no sample exists; TALKATS requires sustain 2, updates the color even with subtitles disabled, and ignores left-click cancellation. Actor color zero falls back to the default speech color. Rendering overrides local palette index 232 (global DOS palette entry 233). Regression tests verify argument consumption, sample completion, click cancellation versus sustain, and cloned-state replay. Full palette allocation and independent reference equivalence remain unverified.

This is incomplete speech/input compatibility: escape counters, complete left-event classification, sample priority rules, scrolling backgrounds, other text speeds, TALK, special font draw flags, and precise palette/text ordering remain outstanding. Null-string reference placeholders and all malformed-input policies also need explicit compatibility decisions.
